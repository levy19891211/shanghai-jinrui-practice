# API 契约文档

> 本文件是前后端对齐的**唯一依据**。任何接口变更必须先更新此处,再实现代码。

## 约定

- 基础地址:开发环境 `http://localhost:4000`(前端通过 `/api` 代理访问)
- 数据格式:`JSON`
- 统一响应结构:

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未认证 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 接口列表

### 1. 健康检查

- **方法**:`GET`
- **路径**:`/api/health`
- **响应**:

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "ok",
    "time": "2026-08-07T05:00:00.000Z"
  }
}
```

### 2. 示例:用户资源(待定)

- **方法**:`GET /api/users`、`POST /api/users`
- **说明**:核心业务确定后在此补充,双方共同维护。
